# Crypto Pug Project

## Descrição
O projeto "Crypto Pug" é um site dedicado a um meme coin de elite, que utiliza tecnologias Web 3.0. O site apresenta uma interface moderna e interativa, com animações e efeitos visuais impressionantes.

## Estrutura do Projeto
```
crypto-pug
├── assets
│   ├── css
│   │   └── styles.css
│   ├── js
│   │   └── script.js
│   ├── fonts
│   ├── videos
│   │   └── background.mp4
│   └── images
├── index.html
└── README.md
```

## Arquivos e Diretórios

- **assets/css/styles.css**: Contém os estilos CSS para o site, incluindo variáveis de cores, tipografia, animações e estilos responsivos.
  
- **assets/js/script.js**: Contém o código JavaScript que gerencia a interação do usuário, animações, efeitos de rolagem suave e outras funcionalidades dinâmicas do site.
  
- **assets/fonts**: Diretório para arquivos de fontes personalizadas utilizadas no site.
  
- **assets/videos/background.mp4**: Vídeo utilizado como fundo na seção hero do site.
  
- **assets/images**: Diretório para imagens utilizadas no site, como logotipos, ícones e outras imagens relevantes.
  
- **index.html**: Página principal do site, estruturando o conteúdo, incluindo seções como cabeçalho, seção hero, tokenomics, roadmap, comunidade e rodapé.

## Como Configurar e Executar

1. **Clone o repositório**:
   ```
   git clone <URL do repositório>
   ```

2. **Navegue até o diretório do projeto**:
   ```
   cd crypto-pug
   ```

3. **Abra o arquivo `index.html` em um navegador**:
   Você pode abrir o arquivo diretamente no navegador ou usar um servidor local para uma melhor experiência.

## Funcionalidades

- **Interface Responsiva**: O site é projetado para ser responsivo e se adapta a diferentes tamanhos de tela.
  
- **Animações e Efeitos**: Inclui animações suaves e efeitos visuais que melhoram a experiência do usuário.
  
- **Integração com Web 3.0**: O projeto é desenvolvido com foco em tecnologias Web 3.0, proporcionando uma experiência moderna e interativa.
