Documentação de Uso

Checklist rápido para abrir o console e verificar se há bloqueio de scripts ou assets.

  1. Abra o site e pressione F12 (ou Ctrl+Shift+I) para abrir o DevTools. Vá na aba Console e veja se há erros em vermelho.
  2. Se aparecer "Failed to load" ou CORS, confira a aba Network: recarregue e filtre por "script" para ver se script.js, tv.js (TradingView) ou a API do Turnstile foram bloqueados.
  3. Desative adblock/anti-tracker ou crie exceção para pugmem.io caso algum domínio apareça como "blocked".
  4. Confirme que as imagens (pug-logo.jpg, WhatsApp*.jpeg/avif) carregam; se não, limpe o cache e recarregue forçando (Ctrl+Shift+R).
  5. Em rede corporativa, verifique se proxies/firewalls filtram cdn (s3.tradingview.com, challenges.cloudflare.com); se sim, peça liberação ou teste via 4G/hotspot.
Qualquer erro listado no console mostra a origem (URL e linha). Copie a mensagem para corrigir ou ajustar whitelist. Scripts essenciais: script.js, tv.js (TradingView), api.js Turnstile.
